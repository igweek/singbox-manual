# sing-box 一键管理脚本

用一个交互式面板安装和管理 [sing-box](https://github.com/SagerNet/sing-box)：添加 / 修改 / 删除节点、申请证书、查看分享链接、更新内核，全程在命令行菜单里完成。

## 支持的环境

| 项目 | 说明 |
| --- | --- |
| 系统 | Debian / Ubuntu（apt）、CentOS / RHEL / Rocky / Alma（dnf、yum）、Alpine（apk） |
| 架构 | x86_64（amd64）、aarch64（arm64） |
| 权限 | 需要 root 用户运行 |
| 网络 | 服务器需能访问 GitHub（下载内核和脚本）；使用域名证书时还需访问证书服务商 |

## 安装

以 root 登录服务器，执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/igweek/singbox-manual/refs/heads/main/install.sh)
```

安装完成后，以后只需输入下面的命令即可打开面板：

```bash
sb
```

> 建议在 `tmux` 或 `screen` 里运行面板。这样即使 SSH 突然断线，操作也不会被打断。

## 面板功能

输入 `sb` 后进入主菜单：

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 添加节点 | 支持 VLESS-REALITY、Hysteria2、TUIC、AnyTLS、VLESS-Argo、Shadowsocks |
| 2 | 更改节点 | 修改 UUID / 密码、端口、节点名称，以及伪装域名、优选域名 / IP、证书类型等 |
| 3 | 删除节点 | 删除指定节点 |
| 4 | 查看节点 | 查看单协议链接，或生成聚合链接，复制到客户端使用 |
| 5 | 证书管理 | 重新申请域名证书、重新生成自签证书、查看证书与自动续期状态 |
| 6 | 运行管理 | 启动 / 停止 / 重启 sing-box |
| 7 | 更新 | 更新内核、更新脚本、强制覆盖重装内核 |
| 8 | 其他 | 开启 BBR+FQ；设置出站使用 IPv4 / IPv6 / 自动（双栈） |
| 9 | 卸载 | 卸载脚本和内核 |
| 0 | 退出 | |

### 关于证书

使用 Hysteria2、TUIC、AnyTLS 等协议时，可以选择：

- **域名证书**：有域名时推荐。支持两种申请方式：
  - 80 端口独立申请：需要服务器 80 端口开放且未被占用。
  - Cloudflare DNS API：适合各类环境，推荐。
- **自签证书**：没有域名时使用。客户端需要开启“允许不安全 / 跳过证书验证”。

### 关于防火墙

添加节点时，脚本会自动识别 `ufw`、`firewalld` 或 `iptables`，并只放行节点所需的端口。已有的规则不会被改写。云服务商控制台里的安全组（如有）仍需你自己放行对应端口。

## 更新

在面板中选择 `7) 更新`：

- **更新内核**：下载并替换 sing-box 内核，配置保持不变。
- **更新脚本**：从 GitHub 获取最新版管理脚本。

## 操作被意外中断怎么办

每次修改配置前，脚本都会先备份当前状态；操作完整成功后才会删除备份。如果中途 SSH 断线、进程被强制结束或服务器断电，备份会保留下来。

**下次运行 `sb` 时，脚本会自动处理，一般无需任何手动操作：**

- 上一次操作没有完成：自动恢复到操作前的状态，并提示一句“已自动恢复到操作前的状态”。
- 上一次操作其实已经成功、只是清理被打断：静默清理，不影响当前配置。

回滚前，脚本会把当前配置和密钥另存一份，放在 `/etc/sing-box/.recovered/`（只保留最近 5 份），万一回滚得不对，可以从这里找回。

如果自动恢复失败，脚本会保留备份并给出提示。此时可以执行：

```bash
sb --recover
```

进入手动恢复菜单：

| 选项 | 作用 |
| --- | --- |
| 1 | 回滚到备份（默认），撤销未完成的改动 |
| 2 | 保留当前配置，把备份归档 |
| 3 | 暂不处理，退出 |

> 选项 2 只有在当前配置通过 `sing-box check` 校验时才允许使用。

## 常见问题

**提示“另一个 sb 正在运行”**

脚本同一时间只允许一个实例修改配置，避免两个进程同时改写。出现这条提示，通常说明：

1. 另一个 SSH 窗口里还开着 `sb`，停在菜单上没有退出。
2. 上次 SSH 断线后，旧进程没有被系统结束。

先退出那个窗口再试。找不到的话，用下面的命令查出进程，再 `kill` 对应的 PID：

```bash
ps -ef | grep "[/]usr/local/bin/sb"
```

**提示发现“疑似残留的隧道服务”**

这是 VLESS-Argo 节点在中断后可能留下的 `cloudflared-*` 服务，配置里已经没有对应节点。脚本不会自动删除，请确认确实不再使用后手动清理。

**提示“检测到未完成的操作”（内核升级、证书迁移等）**

这类中断没法通用地自动恢复，脚本会显示目录说明并让你选择。确认当前服务和配置正常后，可以选择归档备份；不确定时选择“暂不处理”，并联系维护者。

## 重要文件位置

| 路径 | 说明 |
| --- | --- |
| `/etc/sing-box/config.json` | sing-box 主配置 |
| `/etc/sing-box/cert/` | 证书目录 |
| `/etc/sing-box/.recovered/` | 异常恢复时归档的备份（含密钥副本，权限 700） |
| `/usr/local/bin/sing-box` | sing-box 内核 |
| `/usr/local/bin/sb` | 管理面板命令 |

## 卸载

在面板里选择 `9) 卸载`，或重新运行安装命令，在检测到已安装时选择 `2. 卸载脚本 + 内核`。
